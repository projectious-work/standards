# AGENTS.md

This repository is the single source of the projectious.work company
standards. It holds standards text and the delivery script only; products and
company strategy live in other repositories.

## Working here

- A standard changes in `standards/<file>.md`, including its
  `## Agent briefing`. Then run `python3 scripts/standards.py sync`; never edit
  generated skills or the block below by hand.
- `python3 scripts/standards.py sync --check` must exit 0 before a merge.
- Branches, commit titles, and releases follow
  `standards/git-branching-and-releases.md`. Squash merges; the owner approves
  every merge. No GitHub Actions.
- Releases are listed in `CHANGELOG.md` (*Keep a Changelog*) and tagged
  `vX.Y.Z`. A change to a rule is at least a minor version; a rule that
  products must newly act on, or a renamed file, is a major version.
- Keep the text public-safe: no internal strategy, customers, private
  repository names, or internal decision IDs.

Generated from `standards/` by `scripts/standards.py sync`; `standard-*` skills load on demand. *Italic* terms are [Semantic Anchors](https://github.com/llm-coding/Semantic-Anchors/tree/6554641a11fdf99fdbdf09cc0602268e3db88966): canonical meaning applies; standards state only deviations.

### Always on: communication

*BLUF*: answer or next action first; commands, paths, snippets before prose.
Number multi-step work: one bounded action per step, fewest possible.
Restate state across turns; use the harness task tool when one exists.
End with one next action doable in 2 minutes, only if something is open.
Finished work: what works, how to check it, what remains.
Errors: cause, location, fix. Flag unverified claims; never fake certainty.
Estimate human work in minutes or hours, with the assumption.
No preamble, recap, pleasantries, or tangents; offer a second topic after.
Rank lists, 5 per *MECE Principle* group; never truncate reviews or findings.
Safety and confirmation of destructive or outward-facing actions come first;
"explain" gets full depth. Sub-agent briefs and reports are machine-facing:
result, evidence, unknowns.
Details: `standards/agent-communication.md`.

### Always on: execution budget

At most 3 sub-agents at once, in waves; keep core work yourself. Review
gates get 2 rounds, failed verifications 1 rerun, infrastructure failures one
evidenced report to the owner. Push batches, not findings. Never poll.
Details: `standards/agent-execution-budget.md`.
